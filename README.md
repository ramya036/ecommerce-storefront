# Ecommerce Storefront

A multi-page online store front end built with **HTML and CSS**: home, shop, product detail, blog, about and contact pages, all responsive.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

## Pages

| Page | File | What's on it |
|---|---|---|
| Home | `index.html` | Hero banner, featured products and offers |
| Shop | `shop.html` | Product grid across categories |
| Product | `sproduct.html` | Product detail with image gallery and size picker |
| Blog | `blog.html` | Articles and updates |
| About | `about.html` | About the store |
| Contact | `contact.html` | Contact form |

## Run it

Open `index.html` in a browser. No build step needed.
